Per-lane state implied by the function-scope arrays: 7 x 128 floats x 4 bytes = 3584 bytes
per lane. RDNA3 allows 256 32-bit VGPRs per lane = 1024 bytes, so at least part of that
state cannot be register-resident. This is arithmetic on the SPIR-V, not a driver
occupancy or VGPR counter reading; no such counter is exposed by the tooling used here.
